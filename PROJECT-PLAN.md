# Artifact 4 Project Plan

## Purpose
Create a straightforward internship application tracker for a student who is applying to internships and wants to organize opportunities in one place.

## Intended user
A student applying to internships (specific user and interview pending).

## Scope
Build a responsive browser app with create/edit/delete, statuses, search/filter, deadlines, notes, and JSON backup. Avoid backend complexity.

## Ownership and workflow
Solo developer. Work on a feature branch for substantial changes, test locally, then merge into main. No teammates or shared-agent coordination are claimed. The required 2–3-person collaboration component is unmet unless an approved alternative is arranged.

## Acceptance checks
- Applications can be created, edited, and deleted.
- Status counters update correctly.
- Search and status filters return expected results.
- Applications persist after refreshing the page.
- Exported JSON can be imported again.
- Layout works on desktop and mobile.
- Real user feedback is collected and documented before handoff.

## Handoff
Share the deployed GitHub Pages URL with the intended student, demonstrate features, and record feedback. This step remains pending until completed.
