
# Artifact 4 Project Plan

## Project Name

Internship Application Tracker

## Purpose

The goal of this project is to create a simple web application that helps students organize their internship applications. Users can keep track of companies, positions, application statuses, deadlines, and notes in one place.

## Intended User

The application is intended for college students who are applying for internships and want an easier way to track their progress.

A classmate reviewed the completed application and provided feedback as an outside user.

## Project Features

- Add, edit, and delete internship applications.
- Track applications using different statuses.
- Search and filter applications.
- View application statistics.
- Record application dates and deadlines.
- Store job links and notes.
- Save data using browser localStorage.
- Import and export application data as JSON.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub and GitHub Pages
- Claude Code for development assistance

## Development Process

I used GitHub to manage the project and Claude Code to help with implementation and debugging.

I worked on the application form, dashboard, storage functionality, search features, and overall design. I also tested the deployed website and fixed problems I found.

## Testing

The main testing focused on adding, editing, deleting, and saving applications. I also checked the application status counters, search and filtering, and JSON import and export functionality.

I fixed issues with the application form and dashboard styling before sharing the project.

## User Handoff and Feedback

I shared the deployed application with a classmate.

He liked the UI and clean layout. His main suggestion was to make the date field correspond to the application status selected in the dropdown.

I recorded his suggestion as a future improvement. The status-specific date feature has not been implemented.

## Future Improvements

- Connect application dates to individual status changes.
- Add reminders for application deadlines.
- Improve sorting and application organization.
- Continue improving the mobile layout.
