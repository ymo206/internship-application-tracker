
# CLAUDE.md — Internship Application Tracker

## Project Overview

This project is an Internship Application Tracker developed for TCSS 490 Artifact 4 at the University of Washington Tacoma.

The goal is to help college students organize internship applications, monitor their progress, and keep track of important information throughout the application process.

The application is built using HTML, CSS, and JavaScript and is hosted through GitHub Pages.

## Current Features

The Internship Tracker currently supports:

1. Adding internship applications.
2. Editing existing applications.
3. Deleting applications.
4. Tracking application statuses.
5. Searching applications by company or position.
6. Filtering applications by status.
7. Displaying application statistics.
8. Recording application dates and deadlines.
9. Saving application information using localStorage.
10. Importing and exporting application data as JSON.
11. Accessing the application through GitHub Pages.

Application statuses include:

- Saved
- Applied
- Interviewing
- Offered
- Rejected

## Instructions for Claude Code

When working on this project:

1. Read PROJECT-PLAN.md and DEVELOPMENT-LOG.md before making changes.
2. Understand the existing HTML, CSS, and JavaScript before editing.
3. Keep the application simple and easy for students to use.
4. Maintain the current dark-themed dashboard design.
5. Preserve existing features when implementing improvements.
6. Do not remove or overwrite saved application data.
7. Keep the website responsive on desktop and mobile devices.
8. Use plain HTML, CSS, and JavaScript without unnecessary frameworks.
9. Test changes before considering them complete.
10. Update DEVELOPMENT-LOG.md when meaningful changes are made.

## Testing Guidelines

After modifying the application, verify:

- The Add Application form opens and closes.
- New applications can be saved.
- Existing applications can be edited.
- Applications can be deleted.
- Status changes update dashboard statistics.
- Search and filtering work correctly.
- Data remains saved after refreshing the page.
- JSON import and export work correctly.
- The dashboard displays properly on different screen sizes.

Do not claim a feature has been tested unless it has actually been verified.
