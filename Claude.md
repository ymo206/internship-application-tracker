
## Project Overview

This repository contains an Internship Application Tracker developed for TCSS 490 at the University of Washington Tacoma.

The application helps students organize internship applications, track their progress, and manage important deadlines in one place.

## Technology Stack

- HTML5 for page structure
- CSS3 for styling and responsive design
- JavaScript for application functionality
- LocalStorage for saving application data
- GitHub Pages for deployment

## Development Guidelines

- Keep the code clean, organized, and easy to maintain.
- Follow consistent naming conventions.
- Maintain a responsive and user-friendly interface.
- Avoid unnecessary libraries or dependencies.
- Keep application data stored locally.
- Make sure existing features continue working when changes are made.

## Core Features

- Add new internship applications
- Edit and delete existing applications
- Track application statuses
- Search and filter applications
- Monitor application deadlines
- View application statistics
- Import and export application data

## Testing

Before completing changes, verify that:

- Applications can be added, edited, and deleted.
- Search and filtering work correctly.
- Data remains saved after refreshing the page.
- Application statistics update correctly.
- Import and export functionality works.
- The interface displays properly on desktop and mobile devices.
