
# CLAUDE.md - Internship Application Tracker

## Project Overview

This project is an Internship Application Tracker developed for TCSS 490 Artifact 4 at the University of Washington Tacoma.

The goal is to help college students organize internship applications, monitor their progress, and keep track of important information throughout the application process.

The application is built using HTML, CSS, and JavaScript and is hosted through GitHub Pages. Claude Code is used as a development assistant for implementing features, debugging, and improving the project.

## Current Features

The Internship Tracker currently supports:

1. Adding internship applications.
2. Editing existing applications.
3. Deleting applications.
4. Tracking application statuses.
5. Searching applications by company or position.
6. Filtering applications by status.
7. Displaying application statistics.
8. Recording application dates and deadlines.
9. Saving application information using localStorage.
10. Importing and exporting application data as JSON.
11. Accessing the application through GitHub Pages.

## User Feedback and Handoff

The completed application was shared with another student for testing and feedback.

The feedback was positive about the overall UI and clean layout.

One suggestion was to connect the application date field to the selected application status. This could help users keep track of when applications move between different stages.

This suggestion has been documented as a possible future improvement and has not yet been implemented.

The application is publicly accessible through GitHub Pages.
