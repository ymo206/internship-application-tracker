
# Development Log

## Initial Implementation

- Chose to build an Internship Application Tracker to help students organize internship applications and track their progress.
- Created the GitHub repository and set up the project using HTML, CSS, and JavaScript.
- Added the project plan, README, and instructions for Claude Code.
- Built the dashboard with application statistics for total applications, applied, interviewing, and offers.
- Added the ability to create, edit, and delete internship applications.
- Implemented search and filtering by company, position, and status.
- Added application dates, deadlines, job links, and notes.
- Used localStorage to keep applications saved after refreshing the browser.
- Added JSON import and export so users can back up their application data.

## Testing and Improvements

- Tested adding a Microsoft software engineering internship application.
- Confirmed that applications remained saved after refreshing the website.
- Tested editing an application's status from Applied to Interviewing.
- Checked that dashboard statistics updated after changing an application status.
- Tested searching and filtering applications.
- Tested JSON import and export.
- Tested deleting applications and updating the dashboard.
- Fixed an issue where the Add Application button was not opening the form.
- Fixed the dashboard statistics appearing as plain text instead of separate cards.
- Improved the website's CSS, spacing, buttons, and overall appearance.

## Deployment

- Uploaded the project files to GitHub.
- Configured GitHub Pages to deploy from the main branch.
- Published the Internship Application Tracker as a public website.
- Checked that the deployed website loaded and displayed the updated design.

Live Website: https://ymo206.github.io/internship-application-tracker/

## User Feedback and Handoff — November 8, 2026

I shared the completed Internship Application Tracker with my classmate Chris and asked him to test it and provide feedback.

Chris said he liked the UI and thought the layout was nice and clean. He also suggested having the date field correspond to whichever application status is selected in the dropdown.

I thought this was a useful suggestion because it would make it easier to track when an application reaches a particular stage. I documented this as a possible future improvement.

The application was shared through its public GitHub Pages link, allowing Chris to review the finished project.

## Reflection

Working on this project helped me get more comfortable building and testing a complete web application. I spent time fixing issues with the application form, dashboard statistics, and styling. Getting feedback from Chris was also helpful because he pointed out a feature I hadn't considered. His suggestion about connecting dates to application statuses could make the tracker more useful for students managing multiple internship applications.
