
# Internship Application Tracker

An internship application tracker built for TCSS 490 Artifact 4 at the University of Washington Tacoma.

The application helps students organize internship applications, track their progress, and keep important application information in one place.

## Live Application

https://ymo206.github.io/internship-application-tracker/

## GitHub Repository

https://github.com/ymo206/internship-application-tracker

## Features

- Add, edit, and delete internship applications.
- Track application statuses.
- Search and filter applications.
- View application statistics.
- Store application dates and deadlines.
- Save job links and notes.
- Save application data using localStorage.
- Import and export application data as JSON.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages
- Claude Code

## How to Use

1. Open the live application.
2. Click the Add Application button.
3. Enter the company name and position.
4. Select an application status.
5. Add any dates, job links, or notes.
6. Save the application.
7. Edit, delete, search, or filter applications as needed.

Applications are stored locally in the browser. Users can also export their data as a JSON file.

## User Feedback

I shared the completed application with my classmate

He said he liked the UI and thought the layout was nice and clean. One suggestion he had was to connect the date field to whichever application status is selected.

This would help users keep better track of when their applications move through different stages. I documented the suggestion as a future improvement.
