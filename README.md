# Internship Application Tracker

A responsive, browser-based tool for students to organize internship applications, statuses, deadlines, notes, and job links.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Features
- Add, edit, and delete internship applications
- Track Saved, Applied, Interviewing, Offered, and Rejected statuses
- Search and filter applications
- View application counts and deadlines
- Local storage, plus JSON export/import backups
- Responsive layout for phones and computers

## Data privacy
Data stays in the current browser's local storage; there is no server account or cloud synchronization. Clearing browser data can delete applications. Export backups regularly.
